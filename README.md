# Weekly Meal Planner

A [TRMNL](https://trmnl.com) plugin for planning breakfast, lunch, and dinner for every day of the week on an ePaper display.

<img width="150" alt="Works with TRMNL" src="https://trmnl.com/images/brand/badges/light/works-with-trmnl/trmnl-badge-works-with-light.svg" />

## Features

- Plan breakfast, lunch, and dinner for all seven days
- Show or hide individual meal types
- Automatic highlighting of the current day
- Day names in English, German, French, Italian, Spanish, and Dutch
- Layouts for full screen, half horizontal, half vertical, and quadrant views
- Responsive sizing for TRMNL and TRMNL X

## Development

Templates and settings live in [`src/`](src/) and can be previewed locally with [trmnlp](https://github.com/usetrmnl/trmnlp):

```sh
gem install trmnl_preview
trmnlp serve
```

This repository is connected through [TRMNL GitHub Sync](https://help.trmnl.com/en/articles/15977899-github-sync).
